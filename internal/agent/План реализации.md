На каждой ноде запускается Agent

- JOIN отправляет запрос с токеном регистрации в Control Plane
  - Указываем в команде ip:port на котором запущен CP
  - Отправляется запрос на эндпоинт /join в CP
  - Ответ от CP в себе содержит pod_cidr (10.100.NODE.0/24), то есть подсеть для ip адресов подов которые будут запускаться
  - Далее запускается процедура реализации цифровых интервейсов в рамках кластера
